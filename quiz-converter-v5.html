Quiz and H5P Converter

Turns the CSV from the course agents into a Canvas quiz (.zip), or an H5P Question Set, Interactive Book, Course Presentation or Branching Scenario (.h5p), with all feedback included. The page works out which from the header row. Everything happens in this page; nothing is uploaded anywhere.

1. Title and description

2. Paste the CSV

Paste the whole CSV block from the agent, including the header row, or open a saved .csv file. Quiz CSVs start Pool,Pick,Type. Interactive Book and Course Presentation CSVs start Type,Title,Text (CHAPTER rows make a book; SLIDE rows make a presentation). Branching Scenario CSVs start ID,Type,Title,Text,Next. If the agent exported in batches, paste each batch below the last; repeated header rows are ignored.

3. Download

Paste a CSV to see a summary.

Canvas New Quiz

Then in Canvas: create a New Quiz with the same title, open Build, select the Options menu (three dots) > Import Content, and upload the .zip. Leave it unpublished while you preview it. Set attempts, time limit, dates and when students see feedback in the quiz Settings.

H5P Question Set (practice)

Then in H5P: choose Add content > Upload, select the .h5p file, then check it in preview before adding it to Canvas.

H5P Interactive Book

Then in H5P: Add content > Upload, then preview every chapter before adding it to Canvas.

H5P Course Presentation

Each slide has a title, then its text and one activity. Then in H5P: Add content > Upload, then check every slide in preview. To move or resize anything on a slide, open it in the H5P editor.

H5P Branching Scenario

Then in H5P: Add content > Upload, then play through every route before adding it to Canvas.
